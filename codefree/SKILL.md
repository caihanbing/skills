# CodeFree 任务执行

当用户要求用 codefree-o 执行任务时使用本 skill。读取 [CLI 参考](references/cli.md)，结合当前 CLI 帮助确认调用方式。

## 准备交接

提取当前对话最新计划及修订，整理任务目标、验收标准、工作目录绝对路径、相关文件、项目规则、约束、已有改动和验证方式。关键计划或验收信息缺失时先补齐。记录工作区基线，保留用户已有改动。选择用户指定的模型，未指定使用 glm5.3；从实际模型列表解析完整标识，缺失、歧义或不可用时报告，不替换模型；同一任务各轮沿用模型，除非用户调整。

运行记录保存在仓库外，每轮记录交接内容、模型、确切会话标识、输出和 review。通过文件或标准输入传递上下文，避免把正文拼接到 shell 命令；不传递无关隐私或凭证。交接必须限定任务范围及既有授权，提醒执行者保留既有改动，报告实际修改、验证和阻塞。

## 执行与审查

调用 codefree-o 实施，等待进程真正结束。检查实际产物和相对于基线的变更，按验收标准审查正确性并执行适当验证；退出码和模型自述不能单独证明完成。任务实现和修正均交给 codefree-o，Codex 负责交接、审查与验证。

若未达标，反馈具体问题、证据、期望行为和复验要求，优先续接本任务的确切会话；续接不可用时新建会话并提供完整上下文及历史结论。不断审查、反馈和执行，直到验收通过。只要有实质进展不设总轮数；连续三轮无实质进展，或遇到登录、权限、额度等阻塞时暂停，保留恢复信息并如实报告。

最终报告实际模型、轮次、结果、review 与验证证据及剩余问题。不得因委托扩大用户授权。
