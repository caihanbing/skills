# Representative Work Item Evals

- High-risk deletion request with an unspecified retention period, backup policy, rollback strategy, and message compatibility: remain blocked and ask focused questions before writing code or a Work Item plan.
- Medium-risk bug fix with reproduction, root cause, regression test, passing review, and user regression pending: allow `handoff-ready`, reject `closed` until the user records `passed`.
- Low-risk documentation-only change with all impacts `none`: permit the complete lifecycle with `not-required` user regression and Feature Doc evidence.
- High-risk migration missing rollback: reject `handoff-ready` even when tests pass.
