## Bug Fix 闭环

- **症状**：交接模糊及监控耗费额度；恢复用例失败。
- **复现**：旧运行器将 handoff 原文作为输入；基线测试中两项恢复用例各失败两次。
- **根因**：计划与发送内容分离，技能未指定等待策略；blocked 状态拒绝恢复。
- **失败机制**：执行者缺少已保存计划；调用方可能频繁检查；状态门禁拦截 retry/rebuild。
- **修复**：结构化任务校验和合成、静默等待规则、受控异常恢复。
- **回归保护**：交接、任务校验、异常恢复及上下文保留测试。
