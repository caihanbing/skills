## 快速上下文

`codefree/SKILL.md` 规定任务交接、模型选择、审查和持续修正；`codefree/references/cli.md` 记录已验证的 CLI 用法。Codex 依据任务目标独立审查产物，而不是仅依赖执行者的报告。

## 目标与边界

### 目标

- 执行已有计划，反馈审查问题直至满足验收标准。

### 范围内

- 组织上下文、选择模型、调用 CLI、检查产物并续接修正。

### 范围外

- 不替用户扩大授权，也不保证模型服务始终可用。

### 不变量

- 沿用用户指定模型；未指定使用 `glm5.3`，不擅自切换。
- 用户已有变更必须保留，审查依据实际产物和验证结果。

## 业务行为

- 提取最新计划、约束、工作目录和验收标准；关键信息缺失时补齐。
- 每轮保留交接、模型、会话、输出和审查记录；反馈具体问题并继续执行。
- 连续三轮无实质进展或遭遇权限、登录、额度阻塞时暂停并报告。

## 架构与代码地图

- `codefree/SKILL.md` — 入口及执行审查循环。
- `codefree/references/cli.md` — 模型解析、CLI 输入、会话续接和权限说明。
- `codefree/agents/openai.yaml` — 用户界面元数据。

## API、事件与任务

### CLI 调用

- 使用 `codefree-o models` 查找模型，`codefree-o run --dir ... --model ... --format json` 从标准输入接收任务。
- JSON 事件包含会话标识；后续调用以 `--session` 继续具体会话。CLI 不可用或模型不可用时报告错误。

## 数据模型与迁移

不适用：skill 不定义业务数据库模型或迁移；运行记录位于仓库外。

## 核心流程

1. 整理任务上下文，记录工作区基线，核实模型。
2. 调用 codefree-o 并等待退出，读取执行事件。
3. 审查实际修改并执行适当验证；未达标时携带证据续接或重建会话。
4. 验收通过或满足暂停条件时报告结果。

## 异常与边界条件

- 模型缺失或匹配歧义 — 报告问题，不自动替换模型。
- 会话不可续接 — 保存证据并以完整上下文新建会话。
- 连续三轮无实质进展 — 暂停并报告剩余问题。

## 并发与幂等

不适用：skill 不实现共享任务队列或并发控制；执行前需记录工作区基线以识别已有变更。

## 安全与权限

- 交接内容不包含无关凭证或私人信息，使用文件或标准输入避免 shell 展开。
- `--auto` 仅在已授权范围和运行环境允许时使用，不扩大授权。

## 配置与依赖

- 依赖本机 `codefree-o` CLI 和用户可用的模型服务；本机曾验证 CLI 1.10.1。
- 本机当次模型列表中 `glm5.3` 对应 `codefree/GLM-5.3-TokenPlan`；运行时重新解析。
- 本机 Codex 与 codefree-o 的 skill 安装入口以软链接指向仓库维护源；仓库不自动创建这些本机链接。

## 可观测性与运维

- 每轮记录任务交接、模型、会话标识、输出与 review，位于仓库外。
- 可用 `codefree-o debug skill` 检查技能发现。此功能无部署服务、数据库迁移或服务重启步骤。

## 关键决策

### 执行与审查分工

- **决定**：实现与修正交给 codefree-o，Codex 独立审查和验证。
- **原因**：允许复用模型执行，同时依据实际产物判断验收。
- **取舍**：需要保留上下文和会话标识以支持多轮修正。
- **证据**：`codefree/SKILL.md`。

## 已知问题与后续工作

### 模型服务和 CLI 行为依赖本机环境

- **影响**：可用模型、权限及 CLI 参数可能变化。
- **当前处理**：每次查看模型列表和帮助，遇到不可用或歧义时报告。
- **后续动作**：CLI 升级或实际运行暴露问题时重新验证并更新参考文档。
