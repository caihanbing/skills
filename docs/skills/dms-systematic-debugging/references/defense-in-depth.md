# 分层校验

仅当错误会静默造成越权、数据损坏、误删、资金或生产风险时，考虑在同一数据流上增加相称的防护。先修根因，再判断是否需要防护；显示或低后果问题通常只需源头修复。

可按风险选择入口输入校验、业务语义校验、环境守卫和关键操作诊断。约束条件缺失时应安全失败，不能静默放宽租户、权限或删除条件。每一层都应有明确目的，并验证绕过较外层时内层仍能阻止对应错误；不借此重构无关模块。
